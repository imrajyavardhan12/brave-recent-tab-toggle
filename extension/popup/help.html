Recent Tab Toggle setup

Run the installer from the project checkout, then reload this extension:

./scripts/install.sh

Expected status

The extension popup should show Connected and Control + ` is active while Brave Stable is focused.

Helper not found

  1. Run ./scripts/install.sh again.
  2. Open brave://extensions.
  3. Reload Recent Tab Toggle.
  4. Close and reopen Brave if the helper is still not found.

Shortcut conflict

Another application has registered Control + `. Quit or reconfigure it, then refocus Brave.

Fallback shortcut

Open brave://extensions/shortcuts and assign any Chromium-supported key combination to “Toggle the two most recently active tabs.”

Uninstall

./scripts/uninstall.sh

Then remove the unpacked extension from brave://extensions.
